# Klara – Design System

Source of truth for visual decisions. If any skill conflicts with this file, this file wins.

## References
Linear (light mode), Attio, Notion. Calm enterprise SaaS, light and high-contrast.

## Color
- Backgrounds: white and zinc-50.
- Borders: 1px zinc-200.
- Text: zinc-900 primary, zinc-600 secondary. Keep WCAG AA contrast.
- One brand accent: blue-600 (primary buttons, links, focus, active states).
- Status colors are reserved for the traffic light only, never decorative, and always paired with a text reason:
  - green = bereit (ready)
  - amber = fehlt / automatisch korrigiert (missing / auto-corrected)
  - red = blockiert (blocked)

## Typography
- Geist Sans for all text.
- Geist Mono for numbers, timestamps and document IDs.

## Layout
- Generous whitespace.
- **Mobile (site manager):** minimum 48px touch targets, one big round mic button, chat with document cards, full-screen "Klara ruft an" call screen with the Klara robot avatar.
- **Desktop (office):** project tree on the left, case table in the center, detail panel on the right (PDF, evidence, history).

## Mascot
Friendly robot "Klara" on the splash screen, in chat and on the call screen. Friendly but not childish.

## Motion
Subtle and purposeful only: a card appears, a status changes, a call rings. No decorative loops.

## Anti-slop
No purple/blue gradients, no glassmorphism, no default unstyled cards, no lorem ipsum. Use realistic German construction data (real-sounding Bauvorhaben, Gewerke, Nachunternehmer, dates, VOB/B references).
